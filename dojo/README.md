# 明暺的道場（study dojo）

每門課一間道場，各自往上長。線上入口：`https://aadl11.github.io/<repo名>/`

## 結構
```
index.html        總入口
comm-l1/          COMM L1 Public Speaking（✅ Ch 9–11 已開張）
psyc4/            PSYC 4（整備中）
psyc21/           PSYC 21 Race & Identity（整備中）
psyc-c1000/       PSYC C1000 暑期基礎（整備中，本週末搬入）
eng7/             ENG 7 暑期英文（整備中，舊道場檔案搬入）
```

## 每間道場的標配（研究定案的複習方式）
1. **重點地圖** — 三問法問題 1 的一頁骨架
2. **單字** — 必附 🔊 發音（瀏覽器 en-US 語音）＋中文釋義
3. **字卡** — 翻面式 flashcard，可洗牌、可分章
4. **測驗** — 選擇題即時回饋，錯題自動進「認知漏洞清單」（localStorage），可只練錯題
5. **答題台** — Jeopardy 式搶答板，出聲回答再看答案，為課堂 Kahoot 抽考練反應

## 維護規則
- 一課一資料夾、一夾一個 `index.html`，內容全在檔內資料陣列（VOCAB / QUIZ / JEO）——**加題只改陣列，不動骨架**。
- 只增不刪；換週次就換一批陣列內容，舊內容移到註解或 `archive/`。
- 新開一間：複製 `comm-l1/index.html`，改標題與資料陣列即可。
